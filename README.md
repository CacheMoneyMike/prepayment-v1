# Prepayment Views

Selected prepayment charts from an analysis of Ginnie Mae 
mortgage-backed securities (MBS).

## Data

All data comes from Ginnie Mae's publicly available monthly 
disclosure files. Both the data and the analysis are public.

## Charts

The charts cover FHA and VA loan prepayment behavior including 
headline speeds, seasoning ramps, S-curves, and issuer-level 
comparisons.
