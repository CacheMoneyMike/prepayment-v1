FRM Part 1 Quant: Time Series

1. Covariance Stationarity

For a time series to be useful for forecasting, it must be covariance stationary. This requires three strict conditions to hold over time:

  • Constant Mean: The expected value is constant.
  • Constant Variance: The volatility doesn't change over time.
  • Constant Autocovariance: The relationship between periods depends only on the lag distance, not the actual time.

2. Autoregressive AR(1) Model

An AR(1) model links the current value to its immediately preceding value plus a random shock (white noise):

Yt = α + φYt-1 + εt
